Srithar Natarajan - Portfolio Website
=====================================
Files
- index.html                  The complete website (HTML, CSS and JS in one file)
- Srithar_Natarajan_CV.pdf    CV used by the "Download CV" buttons

Run locally
Open index.html in any browser. Keep the PDF in the same folder.

Publish online (free options)
- Netlify Drop: drag the srithar-portfolio folder onto app.netlify.com/drop
- Vercel / Cloudflare Pages / GitHub Pages: upload the folder as a static site

Notes
- Fonts load from Google Fonts, so an internet connection is needed for the exact typography.
- To update text, edit index.html (project data is in the script near the bottom).
